# Evaluación 2 — La raíz que se esconde

**Universidad Católica del Maule · Laboratorio evaluado 2**
Unidad: iteración funcional para ecuaciones — búsqueda de raíces y análisis de convergencia.

Implementación y comparación de seis métodos de búsqueda de raíces (bisección, falsa posición,
punto fijo, secante, Newton-Raphson y Newton-Raphson mejorado) sobre seis funciones de distinta
naturaleza, con tolerancia `1e-6` y un tope de 100 iteraciones. El análisis completo está en
[`informe.md`](informe.md).

**Integrantes:** Blas Rojas Diaz, Joaquin Hernandeez Castro
